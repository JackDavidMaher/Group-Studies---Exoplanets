# How To Read This Repository
Throughout different parts of this project, the repo was used differently.

In its final form the group 1 script was the Group 1 Full Loop Code/automated_spectrum.py file where the .ipynb was used for testing

Group 2 ran their code in different python notebooks inside the Code and Notebooks directories.

Please note that not all notebooks were added to the repo as some of them caused conflics.

For this reason and the fact that sometimes code was worked on collaborativly and then a single person commited, please don't use the insight metrics to judge effort or contribution to the group. We all played to our strengths and some people did more research, some more coding. I would hate for a commit history to be used as a justification for lack of engagment.
